Консольный монитор — без установки, с клавишами

Курсы прямо в терминале с переключением клавишами: тепловая карта крипты, watchlist, лидеры движения; период 24ч/7д/30д. Ничего ставить не нужно — работает встроенными PowerShell / curl. Скрипт лишь скачивает готовые текстовые страницы и печатает их (не парсит и не исполняет удалённый код) — открытый исходник ~20 строк, можно посмотреть по ссылке.

Windows (PowerShell)

irm https://ratescout.ru/cli/rs.ps1 | iex

Исходник: rs.ps1

macOS / Linux (Terminal)

bash <(curl -s https://ratescout.ru/cli/rs.sh)

Исходник: rs.sh

Клавиши: h тепловая карта · w watchlist · m лидеры · 1/2/3 период 24ч/7д/30д · r обновить · q выход. Только для чтения (разовый снимок без запуска скрипта): irm https://ratescout.ru/cli.txt — Windows; curl -s https://ratescout.ru/cli.txt — macOS/Linux. Данные BestChange (цены в USDT), ежечасно. Не оферта, 18+.

Частые вопросы

На каких устройствах работает приложение RateScout?
Android (APK), Windows (портативный zip) и macOS (.app) — один код на всех платформах. Есть веб-версия на ratescout.ru и консольный монитор для терминала (Windows/macOS/Linux) вообще без установки.
Приложение платное? Нужна регистрация?
Нет. Приложение и консольный монитор бесплатны, без регистрации, аккаунтов и подписок.
Откуда берутся курсы?
Данные обменников агрегатора BestChange, как на сайте. Цены приведены к USDT и обновляются ежечасно. Показываются все категории: криптовалюты, банковские карты, онлайн-банкинг, денежные переводы, наличные.
Безопасно ли устанавливать APK на Android и приложение на macOS?
Да. Файлы собираются публично в GitHub Actions из открытого исходного кода. На Android нужно разрешить установку из неизвестных источников (приложения нет в Google Play). На macOS приложение не подписано платным сертификатом — при первом запуске откройте его через правую кнопку мыши → «Открыть».
Что такое консольный монитор и почему он безопасен?
Курсы прямо в терминале с переключением клавишами (тепловая карта, watchlist, лидеры движения; период 24ч/7д/30д). Запускается встроенными средствами (PowerShell или curl) — ставить ничего не нужно. Скрипт только скачивает готовые текстовые страницы с ratescout.ru и печатает их: не парсит данные и не исполняет удалённый код. Исходник открытый (~20 строк): rs.ps1 · rs.sh.
Почему антивирус может ругаться на скачанный файл?
Иногда антивирусы помечают новые неподписанные exe/apk без «репутации» — это ложное срабатывание. Сборки открыты и воспроизводимы в GitHub Actions. Если сомневаетесь — используйте веб-версию или консольный монитор, который ничего не устанавливает.
Чем приложение отличается от сайта?
Приложение показывает тот же монитор, что и сайт, но как отдельная программа на телефоне/компьютере — удобнее держать под рукой. Данные и функции те же.
Это инвестиционная рекомендация?
Нет. RateScout — информационный монитор курсов, не оферта и не инвестиционная рекомендация. Решения об обмене вы принимаете самостоятельно. 18+.
